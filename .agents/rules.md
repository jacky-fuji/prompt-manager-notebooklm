# Git Operations Rules

1. **Explicit Permission for Merges**: Do NOT merge any work/feature/fix branches into `dev` or `main` without explicit permission from the USER.
2. **Explicit Permission for Remote Push**: Do NOT run `git push` to the remote repository (especially for `dev` or `main` branches) without explicit permission from the USER.
3. **Commit First**: Always commit changes to the local working branch first and ask the USER for the next steps.
