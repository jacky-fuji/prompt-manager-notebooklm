# Privacy Policy

Prompt Manager for NotebookLM (the "Extension") values your privacy. This Privacy Policy describes how your data is handled.

### 1. Data Collection and Usage

The Extension does **not** collect, track, or transmit any personally identifiable information (PII) or user data to external servers. All data you create or modify within the Extension is stored locally on your device.

### 2. Data Storage

All data, including:

- Custom prompts
- Favorite status
- Extension settings (language, etc.)

is stored using `chrome.storage.local`. This data remains on your computer and is not synced to any cloud services unless you use internal browser sync features (not currently implemented in this extension).

### 3. Permissions

The Extension requires "host permissions" (e.g., `https://notebooklm.google.com/*`) to:

- Inject prompt insertion buttons into the NotebookLM interface.
- Read the active chat input area to insert your selected prompts.

The Extension only interacts with NotebookLM when you explicitly use its features. No other browsing history or website data is accessed.

### 4. Third-Party Services

The Extension does not use any third-party analytics or tracking pixels.
